# Brain Store
An AI-powered api that allows you to talk to your uploaded document and will only answer based on the information within the provided document. It utilizes Retrieval Augmented Generation (RAG) to overcome the limits of the information of pre-trained model and keep them grounded on what is only provided.

## Overview 
I have build this project because I want to understand how Retrieval Augmented Generation (RAG) works under the hood, the underlying mechanisms and its capabilities.

**Large Language Model (LLM)**

**CI/CD**
